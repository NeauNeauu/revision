## In short

A **matrix** acts on a vector ($A\mathbf x$ = combination of its columns). We multiply them, transpose them, **eliminate** them (pivots, $E_{ij}$), **invert** them (determinant, Gauss-Jordan) and factor them ($A=LU$).

## 1. Matrices

An $m\times n$ matrix: $m$ rows, $n$ columns; entry $a_{ij}$ = row $i$, column $j$. Addition and scalar multiplication: entry by entry.

**Product** $AB$ (defined if columns of $A$ = rows of $B$): $(AB)_{ij}=\text{row}_i(A)\cdot\text{column}_j(B)$, and $(m\times k)(k\times n)=m\times n$.

## 2. Calculation rules

- Addition: commutative, associative, distributive.
- Product: **associative** $A(BC)=(AB)C$; **distributive** $C(A+B)=CA+CB$, $(A+B)C=AC+BC$; **not commutative**.
- Powers: $A^pA^q=A^{p+q}$, $(A^p)^q=A^{pq}$.
- $AB$ = sum of (column $j$ of $A$)×(row $j$ of $B$).
- **Blocks**: if the column cuts of $A$ match the row cuts of $B$, multiply block by block.

## 5. Elimination

- **Pivot** = first nonzero entry of the row used to eliminate.
- **Multiplier** $\ell_{ij}=\dfrac{\text{entry to eliminate (row } i)}{\text{pivot (row } j)}$; do $R_i\leftarrow R_i-\ell_{ij}R_j$.

## 7. Elimination as matrices

- **$E_{ij}$** (elimination) = identity with $-\ell$ at position $(i,j)$: it does $R_i-\ell R_j$. E.g. $E_{31}=\begin{bmatrix}1&0&0\\0&1&0\\-4&0&1\end{bmatrix}$ → $R_3-4R_1$.
- **$P_{ij}$** (permutation) = identity with rows $i,j$ swapped; $P_{23}A$ swaps rows 2 and 3.
- **Augmented matrix** $[A\ \mathbf b]$: same operations on $A$ and $\mathbf b$. $E_{21}[A\ \mathbf b]=[E_{21}A\ \ E_{21}\mathbf b]$.
- $E_{31}E_{21}$ bundles 2 steps into one matrix. **Order matters.**
- $A$ multiplies **each column** of $B$ separately: $AB=[A\mathbf b_1\ \ A\mathbf b_2\ \cdots]$.

## 8. $2\times2$ determinant

**Determinant** of a $2\times2$: $\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$ (diagonal − other diagonal).

- $\det\neq0$ ⇔ **invertible**; $\det=0$ ⇔ no inverse (a pivot is missing).
- Inverse: $A^{-1}=\dfrac1{\det A}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$ — swap $a,d$, flip the signs of $b,c$, **divide by $\det$**.
- Ex: $\begin{bmatrix}2&1\\5&3\end{bmatrix}$: $\det=6-5=1\Rightarrow A^{-1}=\begin{bmatrix}3&-1\\-5&2\end{bmatrix}$; $\begin{bmatrix}1&2\\2&4\end{bmatrix}$: $\det=0\Rightarrow$ no inverse.

## 9. Inverse matrix

- If $A$ is invertible, the **unique** solution of $A\mathbf x=\mathbf b$ is $\mathbf x=A^{-1}\mathbf b$.
- Invertible ⇔ $n$ pivots (exchanges allowed). If $A\mathbf x=\mathbf 0$ with $\mathbf x\neq\mathbf 0$ → **no inverse**.
- Diagonal: invert each entry ($1/d_i$) if no $d_i=0$.
- **$(AB)^{-1}=B^{-1}A^{-1}$** (reversed order), $(ABC)^{-1}=C^{-1}B^{-1}A^{-1}$.
- $E_{ij}$ subtracts $\ell R_j$ → its inverse **adds** $\ell R_j$ (sign of $\ell$ flips).

Cost: factor $\sim n^3$, solve $\sim n^2$ (very worthwhile for several $\mathbf b$).

## 12. Symmetric matrices and permutations

- If $A=A^T$ (no exchanges): $A=LDL^T$ (the $U$ of $LDU$ equals $L^T$). E.g. $\begin{bmatrix}1&2\\2&7\end{bmatrix}=\begin{bmatrix}1&0\\2&1\end{bmatrix}\begin{bmatrix}1&0\\0&3\end{bmatrix}\begin{bmatrix}1&2\\0&1\end{bmatrix}$.
- **Permutation** $P$: rows of $I$ in another order; $P^{-1}=P^T$; there are $n!$ of them (6 for $n=3$).
- If an exchange is needed: **$PA=LU$** ($P$ gathers all exchanges, done in advance).

## Pitfalls

- $AB$ is defined only if **(columns of A) = (rows of B)**; otherwise write “incomputable”.
- $AB\neq BA$; $(AB)^2\ne A^2B^2$.
- Subtract $\ell\times$ the **pivot row**, and apply the same operation to the **right-hand side** $\mathbf b$.
- A zero in the pivot position ≠ failure: look for a row below.
- $E_{ij}$ holds $-\ell$ (not $+\ell$); to undo it you need $+\ell$.
- $0y=8$ → **no** solution; $0y=0$ → **infinitely many**.
- $(AB)^{-1}=B^{-1}A^{-1}$ — **not** $A^{-1}B^{-1}$. Same for the transpose.
- $\det=0$ (or zero column / dependent rows) → no inverse.
- $LDL^T$ needs $A$ **symmetric**; $PA=LU$ if a pivot is zero.
- $\ell_{ij}$ goes **as is** into $L$ ($E^{-1}$ flips the sign, so $L$ holds $+\ell$).

## Key takeaways

- $A\mathbf x$ = combination of columns; $(AB)_{ij}$ = row $i$ · column $j$.
- Matrix product: associative, not commutative.
- Elimination → $U\mathbf x=\mathbf c$ → back-substitution.
- $n$ pivots ⇔ non-singular ⇔ 1 solution.
- $E_{ij}$ subtracts $\ell\times R_j$ from $R_i$; $P_{ij}$ swaps rows.
- $\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$; invertible ⇔ $\det\neq0$ ⇔ $n$ pivots.
- Inverse exists ⇔ $n$ pivots; $[A\ I]\to[I\ A^{-1}]$.
- $A=LU$: $L$ = multipliers (1s on diagonal), $U$ = pivots; solve $L\mathbf c=\mathbf b$ then $U\mathbf x=\mathbf c$.
