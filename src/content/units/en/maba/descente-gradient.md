## In short

[[descente-gradient]] lowers the [[perte|loss]] by moving each weight **against its slope**, with a step of size $\eta$. Repeat until the ground is flat.

## A weight's slope

Change a weight a tiny bit and watch the loss: $\text{slope} = \Delta L / \Delta w$. E.g. $+0.01$ → loss $-0.0048$ → [[pente|slope]] $-0.48$. Computed exactly, it's a [[derivee-partielle]].

- **Sign**: which way to go (always the opposite).
- **Size**: how steep it is.

## The update rule

$$
w_{\text{new}} = w_{\text{old}} - \eta \times \text{slope}
$$

A weight's influence is proportional to **its input**: an input of zero → the weight has no effect.

The [[taux-apprentissage]] $\eta$ is the step size: too small = very slow, too large = overshoots the bottom and the loss **blows up**.

## The gradient and one iteration

The [[gradient]] = the list of **all** slopes. One [[iteration]]:

1. [[propagation-avant]] on every example;
2. compute the loss;
3. compute every slope;
4. update **all** weights at the same time.

Descent stops on **flat** ground: a plateau, a [[minimum-local]] or the true minimum. It doesn't guarantee the lowest point. If the activation is flat, so is the slope → see [[saturation]].

## The cost problem

Measuring each slope by "nudging" each weight takes **one full run per weight**: impractical for millions of weights. Hence exact [[derivee|derivatives]] and [[retropropagation|backpropagation]].

## Pitfalls

- We **subtract** the slope (minus sign).
- A too-large $\eta$ isn't faster: it diverges.
- The slope is local: it changes at every step.

## Key takeaways

- $w \leftarrow w - \eta \times \text{slope}$, for all weights at once.
- Gradient = list of slopes.
- η: neither too small nor too large.
- Flat ≠ necessarily the global minimum.
