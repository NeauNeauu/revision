## En bref

Une **matrice** agit sur un vecteur ($A\mathbf x$ = combinaison de ses colonnes). On les multiplie, on les transpose, on les **élimine** (pivots, $E_{ij}$), on les **inverse** (déterminant, Gauss-Jordan) et on les factorise ($A=LU$).

## 1. Matrices

Matrice $m\times n$ : $m$ lignes, $n$ colonnes ; entrée $a_{ij}$ = ligne $i$, colonne $j$. Addition et produit par un scalaire : case par case.

**Produit** $AB$ (défini si colonnes de $A$ = lignes de $B$) : $(AB)_{ij}=\text{ligne}_i(A)\cdot\text{colonne}_j(B)$, et $(m\times k)(k\times n)=m\times n$.

## 2. Règles de calcul

- Addition : commutative, associative, distributive.
- Produit : **associatif** $A(BC)=(AB)C$ ; **distributif** $C(A+B)=CA+CB$, $(A+B)C=AC+BC$ ; **non commutatif**.
- Puissances : $A^pA^q=A^{p+q}$, $(A^p)^q=A^{pq}$.
- $AB$ = somme de (colonne $j$ de $A$)×(ligne $j$ de $B$).
- **Par blocs** : si les découpes colonnes de $A$ / lignes de $B$ coïncident, on multiplie bloc par bloc.

## 7. L'élimination en matrices

- **$E_{ij}$** (élimination) = identité avec $-\ell$ en position $(i,j)$ : elle fait $L_i-\ell L_j$. Ex : $E_{31}=\begin{bmatrix}1&0&0\\0&1&0\\-4&0&1\end{bmatrix}$ → $L_3-4L_1$.
- **$P_{ij}$** (permutation) = identité avec lignes $i,j$ échangées ; $P_{23}A$ échange les lignes 2 et 3.
- **Matrice augmentée** $[A\ \mathbf b]$ : mêmes opérations sur $A$ et $\mathbf b$. $E_{21}[A\ \mathbf b]=[E_{21}A\ \ E_{21}\mathbf b]$.
- $E_{31}E_{21}$ regroupe 2 étapes en une seule matrice. L'**ordre compte**.
- $A$ multiplie **chaque colonne** de $B$ séparément : $AB=[A\mathbf b_1\ \ A\mathbf b_2\ \cdots]$.

## 8. Déterminant $2\times2$

**Déterminant** d'une $2\times2$ : $\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$ (diagonale − autre diagonale).

- $\det\neq0$ ⇔ **inversible** ; $\det=0$ ⇔ pas d'inverse (un pivot manque).
- Inverse : $A^{-1}=\dfrac1{\det A}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$ — on échange $a,d$, on change le signe de $b,c$, on **divise par $\det$**.
- Ex : $\begin{bmatrix}2&1\\5&3\end{bmatrix}$ : $\det=6-5=1\Rightarrow A^{-1}=\begin{bmatrix}3&-1\\-5&2\end{bmatrix}$ ; $\begin{bmatrix}1&2\\2&4\end{bmatrix}$ : $\det=0\Rightarrow$ pas d'inverse.

## 9. Matrice inverse

- Si $A$ est inversible, **l'unique** solution de $A\mathbf x=\mathbf b$ est $\mathbf x=A^{-1}\mathbf b$.
- Inversible ⇔ $n$ pivots (échanges autorisés). Si $A\mathbf x=\mathbf 0$ avec $\mathbf x\neq\mathbf 0$ → **pas d'inverse**.
- Diagonale : on inverse chaque terme ($1/d_i$) si aucun $d_i=0$.
- **$(AB)^{-1}=B^{-1}A^{-1}$** (ordre inversé), $(ABC)^{-1}=C^{-1}B^{-1}A^{-1}$.
- $E_{ij}$ soustrait $\ell L_j$ → son inverse **ajoute** $\ell L_j$ (le signe de $\ell$ change).

Exemple : $A=\begin{bmatrix}2&1&1\\1&2&1\\1&1&2\end{bmatrix}$ → $A^{-1}=\dfrac14\begin{bmatrix}3&-1&-1\\-1&3&-1\\-1&-1&3\end{bmatrix}$.

Pivots $2,\tfrac32,\tfrac43$ : leur **produit $=4$ = déterminant** ; $A^{-1}$ contient une division par le déterminant (donc $\det\neq0$ nécessaire).

## 11. $A=LU$

Sans échange de lignes : $E_{32}E_{31}E_{21}A=U\ \Rightarrow\ A=\underbrace{E_{21}^{-1}E_{31}^{-1}E_{32}^{-1}}_{L}U$.

- $U$ : triangulaire **haute**, **pivots** sur la diagonale. $L$ : triangulaire **basse**, **1** sur la diagonale et les **multiplicateurs $\ell_{ij}$** en dessous (placés tels quels).
- Variante $A=LDU$ : $D$ = pivots, $U$ a des 1 sur la diagonale.

Exemple : $\begin{bmatrix}2&1&0\\1&2&1\\0&1&2\end{bmatrix}=\begin{bmatrix}1&0&0\\\frac12&1&0\\0&\frac23&1\end{bmatrix}\begin{bmatrix}2&1&0\\0&\frac32&1\\0&0&\frac43\end{bmatrix}$ (car $\ell_{21}=\frac12$, $\ell_{32}=\frac23$).

**Résoudre $A\mathbf x=\mathbf b$ avec $LU$** : 1) factoriser $A=LU$ ; 2) $L\mathbf c=\mathbf b$ (descente) ; 3) $U\mathbf x=\mathbf c$ (remontée).
Ex : $\begin{cases}u+2v=5\\4u+9v=21\end{cases}$, $L=\begin{bmatrix}1&0\\4&1\end{bmatrix}$, $U=\begin{bmatrix}1&2\\0&1\end{bmatrix}$ → $\mathbf c=(5,1)$ → $\mathbf x=(3,1)$.
Coût : factoriser $\sim n^3$, résoudre $\sim n^2$ (donc très rentable pour plusieurs $\mathbf b$).

## 12. Symétrique, permutations

- Si $A=A^T$ (sans échange) : $A=LDL^T$ (le $U$ de $LDU$ vaut $L^T$). Ex : $\begin{bmatrix}1&2\\2&7\end{bmatrix}=\begin{bmatrix}1&0\\2&1\end{bmatrix}\begin{bmatrix}1&0\\0&3\end{bmatrix}\begin{bmatrix}1&2\\0&1\end{bmatrix}$.
- **Permutation** $P$ : lignes de $I$ dans un autre ordre ; $P^{-1}=P^T$ ; il y en a $n!$ (6 pour $n=3$).
- Si un échange est nécessaire : **$PA=LU$** ($P$ regroupe tous les échanges, faits d'avance).

## Pièges

- $AB$ n'est défini que si **(colonnes de A) = (lignes de B)** ; sinon écrire « incalculable ».
- $AB\neq BA$ ; $(AB)^2\ne A^2B^2$.
- On soustrait $\ell\times$ la ligne **du pivot**, et on applique la même opération au **second membre** $\mathbf b$.
- Zéro en position de pivot ≠ échec : chercher une ligne en dessous.
- $E_{ij}$ a $-\ell$ (pas $+\ell$) ; pour l’annuler il faut $+\ell$.
- $0y=8$ → **aucune** solution ; $0y=0$ → **infinité**.
- $(AB)^{-1}=B^{-1}A^{-1}$ — **pas** $A^{-1}B^{-1}$. Idem pour la transposée.
- $\det=0$ (ou colonne nulle / lignes dépendantes) → pas d'inverse.
- $LDL^T$ exige $A$ **symétrique** ; $PA=LU$ si un pivot est nul.
- $\ell_{ij}$ va **tel quel** dans $L$ ($E^{-1}$ change le signe, donc $L$ contient $+\ell$).

## À retenir

- $A\mathbf x$ = combinaison des colonnes ; $(AB)_{ij}$ = ligne $i$ · colonne $j$.
- Produit matriciel : associatif, pas commutatif.
- Élimination → $U\mathbf x=\mathbf c$ → remontée.
- $n$ pivots ⇔ non singulier ⇔ 1 solution.
- $E_{ij}$ soustrait $\ell\times L_j$ de $L_i$ ; $P_{ij}$ échange les lignes.
- $\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$ ; inversible ⇔ $\det\neq0$ ⇔ $n$ pivots.
- Inverse existe ⇔ $n$ pivots ; $[A\ I]\to[I\ A^{-1}]$.
- $A=LU$ : $L$ = multiplicateurs (1 en diagonale), $U$ = pivots ; résoudre $L\mathbf c=\mathbf b$ puis $U\mathbf x=\mathbf c$.
