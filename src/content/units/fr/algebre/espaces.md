## En bref

Un **sous-espace** est stable par addition et multiplication par un scalaire. Deux sous-espaces clés de $A$ : l’**espace colonne** $C(A)$ et le **noyau** $N(A)$. Une **base** = vecteurs indépendants qui engendrent l’espace ; leur nombre = la **dimension**. Les 4 sous-espaces de $A$ ont pour dimensions $r,\ r,\ n-r,\ m-r$.

## 1. Espaces et sous-espaces

- Exemples d'espaces : $\mathbb R^n$ ; les matrices $2\times2$ ($M$) ; les fonctions $f:\mathbb R\to\mathbb R$ ($F$) ; les polynômes de degré $\le n$ ($P$) ; $Z=\{\mathbf 0\}$.
- Il faut : $\mathbf u+\mathbf v$ et $c\mathbf v$ restent dans l'ensemble (+ les règles usuelles : commutativité, associativité, $\mathbf 0$, opposé, distributivité).
- **Sous-espace** : contient $\mathbf 0$ **et** $\mathbf v,\mathbf w\in S\Rightarrow \mathbf v+\mathbf w\in S,\ c\mathbf v\in S$ (⇔ toutes les combinaisons linéaires restent dedans).
- Sous-espaces de $\mathbb R^3$ : **$\{\mathbf 0\}$, droites par $\mathbf 0$, plans par $\mathbf 0$, $\mathbb R^3$**.

## 4. Calculer $N(A)$ et le rang

1. **Élimination** : $A\to U$ (échelonnée), puis $R=\text{rref}(A)$ (pivots = 1, zéros au-dessus **et** en dessous).
2. Colonnes avec pivot = **variables pivots** ; sans pivot = **variables libres**.
3. Pour **chaque variable libre** : la mettre à 1, les autres libres à 0, résoudre → **solution spéciale**.
4. $N(A)$ = toutes les combinaisons des solutions spéciales.

- **Rang** $r$ = nombre de pivots. $\dim N(A)=n-r$ (= nb de variables libres).
- Si $R=\begin{bmatrix}I&F\\0&0\end{bmatrix}$ alors $N=\begin{bmatrix}-F\\I\end{bmatrix}$ (vérif. : $AN=0$).
- **$n>m$** (plus de colonnes que de lignes) ⇒ il y a des variables libres ⇒ **solutions non nulles**.
- Les colonnes libres sont des combinaisons des colonnes pivots *précédentes* ; ces combinaisons donnent les solutions spéciales.
- Rang 1 : $A=\mathbf u\mathbf v^T$ (colonne × ligne), un seul pivot.

## 5. Solution complète de $A\mathbf x=\mathbf b$

Si $A\mathbf x_1=\mathbf b$ et $A\mathbf x_2=\mathbf b$ alors $A(\mathbf x_1-\mathbf x_2)=\mathbf 0$ : deux solutions diffèrent d'un élément du noyau.

1. Réduire $[A\ \mathbf b]\to[R\ \mathbf d]$.
2. **Solution particulière $\mathbf x_p$** : variables libres $=0$, on lit les pivots dans $\mathbf d$.
3. **Noyau** $N(A)$ : solutions spéciales.
4. $\mathbf x=\mathbf x_p+\mathbf x_n$, $\mathbf x_n\in N(A)$.

**Résolubilité** : $A\mathbf x=\mathbf b$ a une solution ⇔ les $m-r$ dernières équations de $[R\ \mathbf d]$ se réduisent à $0=0$. Ex : $A=\begin{bmatrix}1&1\\1&2\\-2&-3\end{bmatrix}$ → il faut $b_1+b_2+b_3=0$.

| Rang | Forme de $A$ | $R$ | Nb de solutions |
|---|---|---|---|
| $r=m=n$ | carrée, inversible | $I$ | **1** |
| $r=m<n$ | courte et large | $[I\ F]$ | **∞** |
| $r=n<m$ | haute et fine | $\begin{bmatrix}I\\0\end{bmatrix}$ | **0 ou 1** |
| $r<m$, $r<n$ | pas de rang plein | $\begin{bmatrix}I&F\\0&0\end{bmatrix}$ | **0 ou ∞** |

- **Rang plein colonnes** ($r=n$) : pas de variable libre, $N(A)=\{\mathbf 0\}$, au plus une solution, colonnes indépendantes.
- **Rang plein lignes** ($r=m$) : $A\mathbf x=\mathbf b$ résoluble pour **tout** $\mathbf b$, $C(A)=\mathbb R^m$.

## 6. Indépendance

Colonnes **indépendantes** : $A\mathbf x=\mathbf 0$ seulement pour $\mathbf x=\mathbf 0$ (elles remplissent tout l'espace). **Dépendantes** : une combinaison non triviale donne $\mathbf 0$ (elles restent dans un plan/une droite).

| $A$ carrée $n\times n$ inversible | $A$ non inversible |
|---|---|
| colonnes indépendantes | colonnes dépendantes |
| $A\mathbf x=\mathbf b$ : **une** solution | **0 ou une infinité** de solutions |

Ex : la matrice « cyclique » $C=\begin{bmatrix}1&0&-1\\-1&1&0\\0&-1&1\end{bmatrix}$ a ses 3 colonnes dans un même plan (leur somme est $\mathbf 0$) → pas d'inverse.

## 7. Indépendance, génération, base, dimension

- **Indépendants** : $x_1\mathbf v_1+\dots+x_n\mathbf v_n=\mathbf 0$ seulement si tous les $x_i=0$ (⇔ colonnes de rang plein). Un $\mathbf 0$ dans la famille ⇒ dépendants.
- **Engendrent** (span) : leurs combinaisons remplissent l'espace.
- **Base** = indépendants **+** engendrent. Alors chaque vecteur s'écrit **de façon unique** dans la base.
- $n$ vecteurs forment une base de $\mathbb R^n$ ⇔ ce sont les colonnes d'une matrice $n\times n$ **inversible**.
- **Plus de $m$ vecteurs dans $\mathbb R^m$ ⇒ dépendants.**

- **Dimension** = nombre de vecteurs d'une base (le même pour toutes les bases).
- Colonnes **pivots** de $A$ = base de $C(A)$ ; lignes pivots (de $A$ ou $R$) = base de l'espace ligne $C(A^T)$.
- Dimensions : matrices $n\times n$ : $n^2$ ; triangulaires sup. : $\tfrac12n^2+\tfrac12n$ ; diagonales : $n$ ; symétriques : $\tfrac12n^2+\tfrac12n$. Base de $\mathbb R^n$ standard : colonnes de $I$.

**Théorème fondamental (partie I)** : $\dim C(A)=\dim C(A^T)=r$, $\ \dim N(A)=n-r$, $\ \dim N(A^T)=m-r$.
Donc $\dim C(A^T)+\dim N(A)=n$ et $\dim C(A)+\dim N(A^T)=m$.

Ex : $R=\begin{bmatrix}1&3&5&0&7\\0&0&0&1&2\\0&0&0&0&0\end{bmatrix}$ ($m=3$, $n=5$, $r=2$) → dims $2,\ 2,\ 3,\ 1$ ; base de $N(R^T)$ : $(0,0,1)$.

## Pièges

- Un sous-espace doit contenir $\mathbf 0$ : une droite/plan **décalé** n'en est pas un.
- $C(A)\subset\mathbb R^m$ mais $N(A)\subset\mathbb R^n$.
- $C(A)\neq C(R)$ en général (les colonnes changent par élimination) ; mais $N(A)=N(R)$.
- Variable libre mise à 1, les **autres** libres à 0 (pas toutes à 1).
- Une base de $C(A)$ = colonnes pivots **de $A$** (pas de $R$ : $C(A)\neq C(R)$). Mais $C(A^T)=C(R^T)$ et $N(A)=N(R)$.
- Solution particulière : libres $=0$, ne pas oublier d'ajouter $N(A)$.
- Indépendants **et** engendrent : un seul des deux ne suffit pas.
- Dimension de $N(A)$ = $n-r$ (colonnes), de $N(A^T)$ = $m-r$ (lignes).

## À retenir

- Sous-espace = contient $\mathbf 0$ + stable par combinaisons.
- $A\mathbf x=\mathbf b$ résoluble ⇔ $\mathbf b\in C(A)$.
- $N(A)$ = combinaisons des $n-r$ solutions spéciales ; rang $r$ = nb de pivots.
- $\mathbf x=\mathbf x_p+\mathbf x_n$ ; résoluble ⇔ $\mathbf b\in C(A)$.
- Base = indépendants + engendrent ; $\dim$ = taille d'une base.
- 4 sous-espaces : dims $r,\ r,\ n-r,\ m-r$ ; $n$ vecteurs de $\mathbb R^n$ = base ⇔ matrice inversible.
- Colonnes indépendantes ⇔ $A$ inversible.
