- [[neurone-mp]] : entrées binaires, poids fixes, seuil, sortie binaire. Poids (1, 1) : seuil 2 = AND, seuil 1 = OR.
- [[hebb]] : apprendre = renforcer les connexions.
- [[perceptron]] : poids **appris** selon les erreurs.
- Limite : AND/OR sont [[lineairement-separable|séparables]], pas [[xor]].
